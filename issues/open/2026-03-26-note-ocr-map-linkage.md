# 注記 OCR と地図調査地点の連携

更新日: 2026-03-26

## やりたいこと

- 地図側の調査地点と、注記 OCR データ上の地点番号を結び付ける
- 注記がある地点を見分けやすくする
- 地点クリックから注記ビューアの該当ページへ飛べるようにする

## 現状

- `calibration-preview.html` では調査地点を表示できる
- `notes-viewer.html` では OCR 済み `pages.json` を読んで地点番号から該当ページを引ける
- 17-19 図については OCR データがあり、地点クリックで注記ビューアへスクロール連動できる

## 検討メモ

- 調査地点の `id` と OCR `location_numbers` は同じ形式なので結合は可能
- OCR データ側から地点番号集合を作り、注記あり地点だけマーカー色を変える案が有効
- ただしこれは OCR ベースなので、OCR 漏れがある地点は「注記なし色」に見える可能性がある
- したがって「注記なし」の厳密判定ではなく、「OCR 上で注記が見つかった地点の強調」として扱うべき

## 今後

- 17-19 以外の OCR セットが揃ったら、`overlay/data/note-ocr/<map-set>/pages.json` を追加して同様に扱う
- 必要なら OCR ページ単位だけでなく、地点番号ごとの索引 JSON を前計算して高速化する
